شب‌وروز - نسخه‌ی نصبی وب (PWA)
==============================
کل این پوشه را روی یک هاست با https بگذار (مثلاً GitHub Pages یا هر هاست ایرانی).
بعد آدرسش را روی گوشی باز کن:
- اندروید (Chrome): منوی سه‌نقطه > Install app / Add to Home screen
- آیفون (Safari): دکمه‌ی Share > Add to Home Screen
بعد از اولین باز شدن، بازی بدون اینترنت هم کار می‌کند.
